K8s overlay network (10.244.x.x) without hostNetwork access, and 
cannot reach the 192.168.122.0/24 virbr0 network where victim-01 
resides. This is a CNI (Container Network Interface) isolation 
constraint, specific to the AWS VPC CNI used by this K3s cluster.

Workaround: The Shuffle Python script calls an HTTP endpoint on the
host machine (192.168.122.1:8199/block), which SSHs to victim-01
and executes the block. In production, Shuffle workers would run
with hostNetwork enabled or the block would execute via a node-local
agent.
